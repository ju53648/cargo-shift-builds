# CARGO SHIFT — VENSUKO

**Current public Windows release: 1.0.1**

[Download CARGO SHIFT 1.0.1](https://github.com/ju53648/cargo-shift-builds/releases/tag/v1.0.1)

CARGO SHIFT is an offline industrial warehouse puzzle game featuring 500 main assignments, five expert exams, 20 training assignments and 15 optional VENSUKO Launcher achievements.

## Installation

Download **cargo-shift-1.0.1-win64.zip** from the release page, extract the ZIP and start **CargoShift.exe**. Windows x64 and Microsoft Edge WebView2 Runtime are required. The game works offline; no account is required for gameplay.

The EXE is currently unsigned; Windows SmartScreen may display a warning. Verify the SHA-256 checksum published with the release.

## VENSUKO Launcher

The public launcher-compatible metadata is in `launcher-manifest.json`, matching the stable game ID `com.vensuko.cargoshift`. The ZIP is hosted directly on GitHub Releases.

**The Launcher 0.16.9 catalog hotfix enables CARGO SHIFT and future games dynamically. Existing Launcher 0.16.8 installations require this one-time update.** Its catalog needs a separate application update, which is prepared privately. No changes to the independent Launcher 1.0.1 workstream are included in this game release.
